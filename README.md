# AOC 2019, in C

See <https://adventofcode.com/2019>

## Input

Get it from the website, put it in the problem subfolder, with name `input`.

## Executable

For tests on examples, use `./main example[1|2] <input>` with `1 or 2` corresponding
to the two parts.

To solve the problem (on the input file), use `./main solve[1|2]`.
